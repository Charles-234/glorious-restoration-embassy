# Glorious Restoration Embassy

A premium Next.js church website built with App Router, TypeScript, Tailwind CSS, Framer Motion, and Supabase.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Environment variables

Create a `.env.local` file with the following values:

- `NEXT_PUBLIC_SUPABASE_URL` — your Supabase project URL.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — your Supabase public anon key.
- `OPENAI_API_KEY` — your OpenAI API key for AI chat responses.
- `ADMIN_PASSWORD` — a secure password for the protected admin console at `/admin`.

Optional:

- `MPESA_NUMBER` — donation number if you want to customize the giving CTA.

## Features

- App Router powered page structure

## Deployment

### Vercel

1. Push this repository to GitHub.
2. Create a new Vercel project and link your repository.
3. Add the environment variables in Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `OPENAI_API_KEY`
4. Deploy the site.

### Supabase

1. Create a Supabase project at https://app.supabase.com.
2. In the Supabase dashboard, go to `Settings > API` and copy the `URL` and `anon` key.
3. Create tables for `newsletter`, `contacts`, and `ai_conversations`.
4. Configure the same keys in Vercel or your local `.env.local` file.

### Admin logs

- Visit `/admin` to see the AI conversation history stored in Supabase.
- The admin console is protected by `ADMIN_PASSWORD` and will redirect to `/admin/login` when not signed in.

### Supabase schema

A ready-made schema is available at `supabase/schema.sql`:

```sql
-- Supabase schema for Glorious Restoration Embassy

create table if not exists public.newsletter (
  id bigint generated by default as identity primary key,
  email text not null unique,
  created_at timestamptz not null default now()
);

create table if not exists public.contacts (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  message text not null,
  created_at timestamptz not null default now()
);

create table if not exists public.ai_conversations (
  id bigint generated by default as identity primary key,
  user_question text not null,
  bot_response text not null,
  created_at timestamptz not null default now()
);
```

Example Supabase table columns:

- `newsletter`
  - `id` (int, identity)
  - `email` (text)
  - `created_at` (timestamp)

- `contacts`
  - `id` (int, identity)
  - `name` (text)
  - `email` (text)
  - `message` (text)
  - `created_at` (timestamp)
